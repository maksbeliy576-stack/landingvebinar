# landingvebinar

Статический лендинг для вебинара «CRM: внедрять или нет?» в визуальном стиле
dm-marketing.pro.

## Файлы

- `index.html` — структура лендинга и тексты блоков.
- `styles.css` — адаптивное оформление страницы.
- `assets/` — логотип dm-marketing.kz и фото Максима Дедяева для страницы.
