# landingvebinar

Статический лендинг для вебинара «Система B2B-продаж: бренд, контент и CRM»
в визуальном стиле dm-marketing.kz.

## Файлы

- `index.html` — структура лендинга и тексты блоков.
- `styles.css` — адаптивное оформление страницы.
- `assets/` — логотипы, фото Максима Дедяева, изображения кейсов, логотипы клиентов,
  благодарственные письма и логотипы партнёров.
